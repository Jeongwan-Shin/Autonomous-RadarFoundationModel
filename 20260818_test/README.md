# v12 테스트 꾸러미

`vlm_8B_v12` (step 8,330) 를 다른 서버에서 돌리기 위한 것. 원본 데이터셋도,
기반 모델 17 GB 도 필요 없다 -- 번들에 모델이 실제로 받는 것만 들어 있고,
토크나이저와 프로세서 설정은 `base/` 에 있다.

## 옮길 것

| | 어디서 | 크기 |
|---|---|---|
| 이 폴더 | 저장소 | ~12 MB (`data/` 제외) |
| `dist/v12_step8330.tar` | 모델 | 16.5 GB |
| `dist/data_v12_bundle.tar` | 데이터 번들 | 121 MB |

`data/` 는 저장소에 넣지 않는다. 재생성 가능한 산출물이고 한 번 커밋하면
히스토리에서 지워지지 않는다.

## 실행

    tar xf v12_step8330.tar          # -> v12_step8330/
    tar xf data_v12_bundle.tar       # -> data/
    pip install -r requirements.txt
    python run_eval.py --checkpoint v12_step8330 --items 20

결과는 `results/scores.json` 과 `results/generations.jsonl` 로 나온다. 생성물을
남기는 이유는 채점이 지금까지 네 번 틀렸기 때문이다 -- 지표는 텍스트에 대한
의견이고, 의견은 나중에 고칠 수 있어야 한다.

## 동작 확인 (10 클립, 태스크당 20건)

    det_objects_3dbbox   F1 0.727  거리MAE 0.55m  방위MAE 0.99deg  속성 96%
    det_objects_azdeg    F1 0.753  거리MAE 0.33m  방위MAE 0.80deg
    plan_ego_xy          L2 0.300 m

**이 숫자는 지표가 아니다.** 클립이 열 개뿐이고 쉬운 쪽이다. 같은 체크포인트를
30,916 클립의 테스트 분할에서 태스크당 60건으로 재면 3D F1 0.60, L2 0.91 m 다.
여기 숫자는 "꾸러미가 제대로 돌아간다" 는 확인이지 성능이 아니다.

## 이 폴더가 v12 전용인 이유

저장소의 현재 코드로는 이 체크포인트가 **열리지 않는다.** 세 군데가 어긋난다.

| | 저장소 현재 (v14) | v12 (이 폴더) |
|---|---|---|
| 극좌표 격자 | 16 x 4, 프레임마다 | **32 x 8, 창 전체에 하나** |
| 레이더 토큰 | 640 | **256** |
| 레이더 스캔 | 10 | **20** |

그래서 `ravl/` 은 커밋 `9a04540` 에서 떠 왔고, 번들도 그 커밋의 작업 트리에서
뽑았다. 저장소를 최신으로 체크아웃해 이 체크포인트를 열면 `polar_query` 가
(256, 384) 대 (64, 384) 로 어긋나며 죽는다.

## 조용히 틀리는 것들

돌려 보면 오류가 나지 않는데 점수만 무너지는 자리가 셋 있다. 전부 실제로
겪은 것이다.

**1. 어휘 파일.** `ravl/number_vocab.txt` 는 5,080 줄이어야 한다. 커밋
`9a04540` 의 것은 4,607 줄이다 -- v12 는 5,080 으로 학습했는데 그 파일이
`afac691` 에서야 커밋됐다. 어긋나면 숫자 토큰의 id 가 밀려 출력이 통째로
어긋나는데, 아무 오류도 나지 않는다.

**2. 프레임 크기.** 번들은 1920x1088 로 저장하고 `run_eval.py` 가 태스크마다
줄인다. 384 로 저장해 두면 검출의 비전 토큰이 프레임당 1,020 이 아니라 42 가
되어 det F1 이 0.727 에서 **0.017** 로 떨어진다. 그런데 계획은 자차 상태가
프롬프트에 문장으로 있어 0.263 m 로 멀쩡해 보인다 -- 한 태스크만 보고 있으면
모른다.

**3. 레이더 주입.** `inputs_embeds` 로 넘기면 Qwen3-VL 의 비디오 스캐터가
꺼진다. 입력 임베딩 모듈에 forward hook 을 걸어 자리표시자 행만 덮어써야 하고,
`run_eval.py` 가 그렇게 한다. 이 부분을 바꾸면 점수가 조용히 무너진다.

## 번들을 다시 만들려면

원본 데이터셋이 있는 서버에서, v12 커밋의 작업 트리로:

    git worktree add /tmp/v12tree 9a04540
    cp training/number_vocab.txt /tmp/v12tree/training/    # 5,080 줄짜리로
    PYTHONPATH=/tmp/v12tree python /tmp/v12tree/20260808_test/export_items.py \
        --clips 10 --split test --out 20260818_test/data

## 이 체크포인트의 알려진 한계

**레이더가 기여하지 않는다.** 다른 클립의 레이더로 바꿔 넣은 대조군과의 F1 비가
39 개 측정점 내내 평균 1.10 이었다. 성적은 카메라와 자차 상태에서 나온 것이다.
원인 둘은 밝혀졌고 v14 에서 고치는 중이다 -- polar readout 이 프레임을 펼쳐
모아 시간 축이 사라졌고, 카메라를 지우는 학습 항목이 하나도 없었다.
